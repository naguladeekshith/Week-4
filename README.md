# Week-4
This report documents the complete development and evaluation of a machine learning model in Python. The problem is binary classification: predicting whether a breast tumour is malignant or benign using the Breast Cancer Wisconsin (Diagnostic) dataset, which has 569 samples and 30 numeric features. Malignant was treated as the positive class because missing a cancer is the more serious error, so recall and F1-score were prioritised alongside accuracy and ROC AUC. Data preparation included checking for missing values and duplicates, encoding the target, a stratified 80/20 train-test split, and feature scaling inside a scikit-learn Pipeline to prevent data leakage. Four algorithms were compared using stratified 5-fold cross-validation and tuned with GridSearchCV: logistic regression, K-nearest neighbours, decision tree and random forest. Logistic regression was selected on cross-validated F1 before the test set was touched. On unseen data it achieved about 96.5% accuracy, 92.9% recall and a ROC AUC of 0.996. The evaluation uses confusion matrices, ROC curves, a metric comparison chart, a depth curve and a learning curve to analyse overfitting and underfitting. I also examined feature importance, the individual misclassified cases and the effect of moving the decision threshold, and checked the reliability of the result across ten random splits. The report ends with a critical discussion of error sources, such as small sample size, single-source data and collinear features, and suggestions for improvement, such as calibration, cost-sensitive learning, nested cross-validation and external validation. The Python code and dataset are included.
